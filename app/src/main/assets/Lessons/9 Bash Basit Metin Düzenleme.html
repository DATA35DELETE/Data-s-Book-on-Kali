Basit Metin Düzenleme

Nano Nedir?

Linux'da içinde bulunduğu GNU projesindeki bir metin düzenleme aracıdır. nano dosya
Nano, konsol üzerinden dosyalarımaza yazılar yazmamızı sağlar. Böylelikle direk komut satırınında metinlermizi düzenliyebiliriz. Ayrıca Cat ile dosyamızın içeriğini görebiliriz. Eğer bir yazılım diliyle kod yazıyor isek, renkli kodlar görünümü sağlar.
Şimdi oluşturduğumuz klasördeki "dosya" isimli dosyamızı içine "Kali Öğreniyorum" yazalım. Ardından Cat ile yazılanı konsolda görelim.
cd kodlar
nano dosya
# Gelen ekranda
Kali Öğreniyorum
# Ctrl + O + Enter, Ctrl + X
cat dosya

Kısayollar

Ctrl + O + Enter

Dosyayı kayıt eder.

Ctrl + X

Dosyadan çıkar.

Alt + U

Geriye alır.

Alt + E

İleri alır.
