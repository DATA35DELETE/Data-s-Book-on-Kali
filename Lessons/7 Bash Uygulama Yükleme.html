APT

Apt, Debain ve onundan türemiş işletim sistemlerindeki paket yöneticisidir. Kali, Debain'den türediği için Apt kullanıyoruz. Paket yöneticisi ise, Linux tarzı işletim sistemlerinde uygulamalarımızı tek komutla indirebildiğimiz ve silebildiğimiz bir araçtır. Yerel yani Apt sunucularında bulunmayan paketleri ise Dpkg ile kuruyoruz.

Kullanımı

sudo apt install PaketIsmi
Bu komutta; Sudo bir nevi Admin yetkisidir.
Apt Install ile "PaketIsmi" paketimizi indiriyoruz. Örneğin yazılan isimi, sosyal mecralarda aramamızı sağlayan Sherlock paketini indirelim. İlk başta şifrenizi istiyecektir. Konsolda şifre gözükmesede yazılıyordur.
sudo apt install sherlock

Paket Arama

Eğer indiriceğimiz paketin ismini bilmiyorsak;
apt search PaketIsmi
        
"PaketIsmi" kelimesini içeren tüm paketleri yazdırır.

Yerel Paketleri İndirme

Eğer Apt'de istediğiniz paket yok ama elinizde .deb uzantılı bir dosyanız varsa, Dpkg ile sistemize kurabiliriz.
İndirdiğimiz paketin klasörüne gelelim ve sağ tıklayalım. Ardından "Burada Uçbirim Aç" diyelim. Yaptığımız işlem bizi indirdiğimiz .deb dosyamızın klasöründe bir konsol açar. Ve sonra;
sudo dpkg -i PaketIsmi.deb
        
Apt'deki gibi indiricektir.
